Send records to a Google Sheet (optional)

Do this once so every device saves to the same online sheet. Staff do not need to log in.

  1. Open a Google Sheet. Go to Extensions > Apps Script.
  2. Delete what is there. Paste the script below. Save.
  3. Click Deploy > New deployment > Web app.
  4. Set "Execute as" to Me and "Who has access" to Anyone. Click Deploy.
  5. Copy the web app link and paste it here.
