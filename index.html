Connect your Google Sheet (optional)

Do this once. Then every device can load the tracker from the sheet, and saved audits go to a tab called "App Audit". Photos go to a Google Drive folder called "Inventory Audit Photos". Staff do not need to log in.

  1. Open the eBay Listing Audit Tracker in Google Sheets. The list tab must be named "Listing Tracker".
  2. Go to Extensions > Apps Script. Delete what is there, paste the script below, and save.
  3. Click Deploy > New deployment > Web app.
  4. Set "Execute as" to Me and "Who has access" to Anyone. Click Deploy and allow access.
  5. Copy the web app link and paste it here.

Already set up an older script? Replace it, then use Deploy > Manage deployments > Edit > New version.
